# Varun K S – Portfolio

Static site (HTML, CSS, JS). No build step.

## Open in VS Code
1. File > Open Folder... and choose this folder.
2. Install the "Live Server" extension, right-click `index.html`, choose "Open with Live Server".
   (Or run `python -m http.server 8000` in the terminal and open http://localhost:8000)

## Files
- `index.html` – structure and text
- `style.css` – design (colors in `:root` variables, light theme under `[data-theme=light]`)
- `script.js` – projects, experience, terminal answers, contact popup
- `assets/bg-desktop.jpg`, `assets/bg-mobile.jpg` – page background made from `profile.jpg`
- `assets/profile.jpg` – original photo, `assets/photo.jpg` – small round avatar
- `assets/Varun_K_S_N26.pdf` – resume used by the Resume button

## Publish on GitHub Pages
Push this folder to your `portfolio` repo, then Settings > Pages > Deploy from branch `main` / root.
